Reference copy of the drinkEffects hook source. The maintained version is in the Plus repository (branch `yo-engine-hooks`, file `source/server/hooks/engine/`).

hook_craft_effects_range.cpp/.h: raises the item_effects.xml effect id limit from 1..38 to 1..127 (config <craftEffectsRange enabled="1"/>), needed for the Geselle/Meister outfit effects (see docs/research-notes/12).

Hooks ported from Daniel's mods (2026-10-04), wired into Plus like the others, logging to logs/agriculture.log via agri_log.h:
- hook_plow_cart_parity: removes the plough exception from the cart tuning branch (server RVA 0x9E34D); needs the client twin (tools/patch_client_plow_parity.py).
- hook_harvest_soil: harvested tiles go back to settled soil (RVA 0x3A9759).
- hook_plow_area: plowing loosens a 3x3 area (RVA 0x3A5FD1).
- hook_log_description, hook_saw_output, hook_ability_entity_check: let extra log types be examined and sawn (RVAs 0x39633C, 0x39E761, 0x39EE12); the client saw menu needs tools/patch_client_saw_menu.py.

hook_tunnel_inspect.cpp/.h (2026-10-09): inspecting a tunnel tile with timber (boards/column) shows message 5213 "supported, will not collapse" instead of the day count (call site RVA 0x397AF5, config <tunnelInspect enabled="1" messageId="5213"/>). Wired like the others: ConfigureTunnelInspect(root) next to ConfigureLogDescription, AttachTunnelInspectHook() next to AttachLogDescriptionHook in cm_server.cpp. Message text: client/data-additions/tunnel_supports. Pairs with server/mods/LiFx/TunnelSupportsPack (timber decay 0), see docs/research-notes/16.

hook_gather_quantity.cpp/.h (2026-10-09): random gather amount per gatherable type (detour of Gathering::GetQuantitybyGatherType, RVA 0x3797C0), config <gatherQuantity enabled="1"><range type="14" min="10" max="20"/></gatherQuantity> (plant fiber 10-20). Wired with ConfigureGatherQuantity(root) after ConfigureTunnelInspect, and AttachGatherQuantityHook() AFTER AttachCropTypesHook in cm_server.cpp (the crop hook patches the cmp inside this hook's 14 bytes; attaching earlier crashes the boot). See docs/research-notes/03.

hook_animal_fodder.cpp/.h (2026-10-13): fodder items count as animal feed, newborn animals get +newbornBonus quality while their species' fodder is in the building, the vanilla in-stable quality gain from feeding is switched off (two `INC R8B` NOPs at RVA 0x1B33AC / 0x1B33FC), and slaughter products get +slaughterBonus quality in the configured in-game months. Detours: feed predicates 0x1B0E70 / 0x1B0E10, CmStable::bornAnimal 0x1AC2E0, _slaughterAddProduct 0x1ABD00; getGameTime body 0x468760. Config `<animalFodder enabled="1" ...>` (see lifxpluss.example.xml). Wired with ConfigureAnimalFodder(root) after ConfigureStableAlias and AttachAnimalFodderHook() after AttachStableAliasHook in cm_server.cpp. The client has its own feed list: tools/patch_client_feedmask.py. Pairs with server/mods/LiFx/AnimalFodderPack. See docs/research-notes/19.

hook_stable_alias.cpp/.h (2026-09-21, extended 2026-10-13): custom buildings behave as a vanilla animal building. A rule `<stable objectTypeId="N" behavesLike="144" maxAnimals="30" product="0" allowAnimals="1053"/>` rewrites the boot query's type list (RVA 0x7A1210, one extra 4-digit id fits), detours the parameter-table getters (0x1B0EB0, 0x1B0D60, 0x1B04D0, 0x1B0D20, 0x1B0410, 0x1B07E0) and wraps checkContainerLimits (0x1AC440) for the species rule; since 2026-10-13 a behavesLike="144" type also gets the Manage ability gate patched (ManageAnimals_Ability::checkEntity, 18 bytes at RVA 0x35502A, one type). The client needs three exe patches (tools/patch_client_stablegate.py, patch_client_stablewindow.py, patch_client_stabletable.py). See docs/research-notes/05 and 20.
