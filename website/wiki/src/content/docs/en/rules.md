title: Server rules
description: The binding rules for the Discord and game server of the Wulpische Lande.
---

By entering the server you accept these rules. Rules on KoS, claims and workshops are in the [server concept](/en/concept/). (The German text is the original.)

## §1 General

1. The server is exclusively for persons aged 18 and over.
2. The server management holds the house rules. Rule changes can be made binding at any time.
3. German law applies to the server and related services.
4. The operators accept no liability for damage or legal violations in connection with the use of the server.
5. Nicknames must contain the game character's name and must be neither insulting nor unlawful.
6. Avatars with pornographic, racist, discriminatory, insulting or unlawful content are prohibited.
7. Attacks on the server (e.g. DDoS) will be prosecuted consistently.
8. Private data must not be published.
9. Insults, discrimination, spam, advertising for third parties and the exploitation of bugs are prohibited.
10. Ignorance does not protect against punishment.
11. Server members are to be treated with respect.

## §2 Voice chat

1. Recording other users' audio without their consent is prohibited.
2. Bots may only be used with the permission of the server management.
3. Channel hopping is prohibited.

## §3 Chat

1. Aggressive behaviour, insults and obscene or unlawful content are prohibited.
2. Disputes are to be settled through the ticket system.
3. Matters with the server team are discussed in private only.

## §4 Publications

1. Passing on internal server information without permission is prohibited.
2. Image recordings for evidence purposes are allowed but may only be used within the server.

## §5 Sanctions

1. Violations can be punished with mutes, kicks and temporary or permanent bans.
2. Anyone who was punished unjustly can contact the team.
3. In case of dispute, the team's decision is final.
4. In case of rule violations, the operators reserve the right to take measures outside the server as well.
