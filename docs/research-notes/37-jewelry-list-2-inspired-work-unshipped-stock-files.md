# 37 Jewelry list 2, the Inspired Work ring, and stock files that were never shipped

- **Jewelry list 2** (`server/data-additions/jewelry_item_effects.xml`, `tools/apply_jewelry_list2.py`): Intelligence is gone from all jewelry. Sapphire ring (496) = Strength 0.5-1.5 + Willpower 0.5-1.5, Exceptional ring (498) = Strength 1-3 + Willpower 1-4 + Constitution 1-5, Exceptional amulet (491) = Strength 2-5 + Willpower 2-6 + Agility 2-7; the rest unchanged. Effects of an item are rolled when it is created and stored per item in `item_effects` (ItemID, EffectID, Magnitude x1000), so existing items need an SQL update on the database as well as the XML (value = min + (max-min) * quality / 100). The VPS database is `lif_1` (HeidiSQL: Abfrage tab -> Datei -> SQL-Datei laden).
- **Inspired Work as a ring buff** (tried, then replaced by the list above): cm effect 88 (CAST_DURATION DECREASE 0.8, magnitude ignored, -20% time to perform abilities); it needs a DB row in `effects` (new id 58, PlayerEffectID 88) before the server starts, and its tooltip text (message 4506) talked about a meal.
- **Stock files changed on the playing client were never in the pack.** The release is built from a stripped source folder while the player's install holds the full game, so edits made inside the install (darker night = `art/datablocks/envData.cs` + `art/Textures/Weather/raindrops.dds`, custom cursor = `core/scripts/gui/cursors.cs` + `core/scripts/client/core.cs`, animal/tree/log datablocks, two icons, `gui/scripts/messageWindow.cs`) never reached testers. `tools/list_modified_stock_files.py` lists every stock file of an install that differs from the Steam depot manifests and whether the release manifest ships it. Run it before a release.
- **PowerShell traps** (they cost files once): `rd` is an alias of `Remove-Item`, so a helper function named `Rd` deleted five files instead of reading them (restored from the backup taken right before); variable names are case-insensitive (`$g` overwrote `$G`). Write file edits as Python scripts with a backup first.
