# 28 SF Mods window, armor effects, stonecutter skill, books over http

- **item_effects.xml ids are DATABASE effect ids**, not cm_effects ids: `<effect id="28">` = table `effects` row 28 "Impact mitigation" -> `PlayerEffectID` 68 -> `cm_effects.xml` effect 68. effects.ID 27-36 are the mastery effects (cm 67-76) that vanilla armor carries. Using the cm_effects id (68) in item_effects.xml silently does nothing.
- **Armor** (`client/data-additions/armor_effects`, `server/vps/apply_impact_mitigation.ps1.txt` (paste into an admin PowerShell in the server folder)): the old mastery effects were removed from all 130 armor pieces (grandparent type 24-28: padded, leather, chain, scale, plate; id list included), then "Impact mitigation" was added to 105 of them (not Novice/Regular Padded and Leather). Effect 68 carries the action slow-down: `CAST_DURATION INCREASE 1.2` (stock evidence: effect 88 "Inspired Work" is `CAST_DURATION DECREASE 0.8`, "20% less time to perform abilities"; `MULTIPLY` is NOT honoured for CAST_DURATION), `ATTACK_SPEED MULTIPLY 0.8`, `RANGED_ATTACK_SPEED MULTIPLY 0.8`, all `ignore_magnitude="1"`. Confirmed in game: a 15 s action takes ~18 s.
- **Message texts are format strings**: a percent sign must be written `%%` (stock text 4506: "20%% weniger Zeit"). A single `%` made the tooltip description vanish.
- **Stonecutter outfits** 3591/3653: equip skill changed in `cm_equipTypes.xml` (client and server) from 16 Digging to 17 Materials preparation (still 60).
- **Books on a Cloudflare site**: the client reads titles and tickets with `SimDownloadHelper`, the engine downloader, which has no TLS. `$BooksPack::baseUrl` must therefore be plain `http://...` (Cloudflare serves http without redirect); `booksOpen()` upgrades the page itself to https for the browser window.
- **SF Mods window** (`client/scripts/SFModsPatch`): the compiled mod cannot be replaced (a decompiled GUI crashed the client), so a script re-arranges it. Tree dumped with `sfTabsDump` into `data/sf_tree.txt`: tab buttons are direct children of `SFGuiWindowCtrl` (internal names `SFGuiButton<Tab>`, the Chat button only has the object name `SFGuiButtonLChat`), panes `SFGuiPane<Tab>`, bottom buttons in `SFGuiContButtons`. New look: vertical column of tabs, fixed 412x400 window (the per-tab `sfWindowResize<Tab>()` functions are replaced by empty ones via `eval`), parchment panel behind the controls (moved to the back with `reorderChild`/`bringToFront`/`pushToBack`, verified after each call), dark text and green gold-framed buttons through new window-only profiles; Block, Antidote and GFX hidden. A watch loop re-applies it every second because the window is built a few seconds after start.
