# 27 AmIAlive watchdog and QuickJoin main-menu button

- **AmIAlive** (`tools/amialive`): small C# watchdog for the VPS. It starts `Start_LiF_Server_VPS.bat` when `ddctd_cm_yo_server.exe` is not running, stays quiet for 120 s after each start, never restarts during a planned restart (`AmIAlive.exe restart` writes the mark `AmIAlive.restart`, `stop` writes `AmIAlive.stopped`, `start` removes it), closes cmd windows of the start bat older than 120 s, pauses for 15 min after 5 deaths in 10 min, runs once per folder (mutex). Installer = scheduled task "AmIAlive" at boot (SYSTEM) replacing the old "LiF Server" task. Freshly built unsigned exes may be blocked by Windows policy: logic was tested by loading the assembly in-process (`AMIALIVE_DIR` points it at a test folder).
- **QuickJoin** (`client/scripts/QuickJoin`): the main-menu button "Join a world" calls `MainMenuMultiplayerWindow::OnJoinWorldBtnClick`; a package override connects with the game's own `joinToRemoteServer(address, password)` (`scripts/yo.cs`, also used by the dev button "Local Server"). `$QuickJoin::enabled = 0` restores the server browser. Client mods are loaded by `exec(...)` lines at the end of `art/materials.cs`. The repo copy has placeholder address/password; the password is plain text in a client file, so it only keeps casual joiners out.
