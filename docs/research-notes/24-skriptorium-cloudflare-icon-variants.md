# 24 Skriptorium on Cloudflare, icon variants

- **Skriptorium website** moved from a local Express + SQLite app to a Cloudflare Worker + D1 (`tools/skriptorium-cloudflare`). Same pages and API paths, so `BooksPack` only needs `$BooksPack::baseUrl` (public address, https, no trailing slash) and `$BooksPack::tabletAdminKey` (= the Worker secret `TABLET_ADMIN_KEY`). Differences: PBKDF2-SHA256 (WebCrypto) instead of bcrypt for new book passwords (bcrypt too slow for Worker CPU; legacy bcrypt hashes are still verified via bcryptjs), HTMLRewriter whitelist instead of sanitize-html. Deploy with `wrangler` (the `cf deploy` command does not read `wrangler.jsonc`); set secrets without a trailing newline (`cmd /c "<nul set /p=KEY| npx wrangler secret put TABLET_ADMIN_KEY"`). Cloudflare answers 403/1010 to the default Python urllib user agent; the game's HTTP client and an empty user agent pass.
- The game client learns the web address from the server at the first document lookup and caches it for the whole session: after changing `baseUrl` restart the server AND relaunch the client.
- **Item icon variants.** Items have a hover variant `<name>_h.png` (911 files; some `_i.png`) that must have exactly the same size as `<name>.png`. Resizing only the main icon makes items jump in size on hover. The game draws icons at their file size; vanilla icon sizes also vary with the item class (`Length`). Any resize must treat main + `_h` + `_i` together (checker script lists mismatches).
